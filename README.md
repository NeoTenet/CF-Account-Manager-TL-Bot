## 🌟 ویژگی‌های برجسته

- ⚡️ **لینک جادویی ساخت توکن (تک‌کلیک):** تولید مستقیم توکن کلودفلر با تنظیم خودکار `All accounts` و `All zones` بدون نیاز به دستکاری دستی و بدون هیچ‌گونه خطای قرمز!
- 🚀 **پشتیبانی کامل از ES Modules:** رفع کامل خطای مرسوم `SyntaxError: Unexpected token 'export'` با استفاده از متادیتای اختصاصی `multipart/form-data`.
- 📁 **داشبورد تعاملی ورکرها:** نمایش فهرست تمام ورکرهای فعال اکانت با دکمه‌های شیشه‌ای، امکان انتخاب و بازنویسی کد یا ساخت ورکر جدید.
- 🔐 **مدیریت سکرت‌ها (Workers Secrets):** مشاهده سکرت‌های ثبت‌شده و ثبت مقادیر امن (مانند `UUID`، پسوردها یا توکن‌ها) روی ورکر.
- 🗄 **دیتابیس KV Storage:** ایجاد خودکار فضای ذخیره‌سازی KV Namespace و اتصال (Bind) مستقیم به کد با نام متغیر دلخواه.
- 💾 **دیتابیس D1 SQL (پایگاه داده رابطه‌ای سرورلس):** ساخت آنی دیتابیس رابطه‌ای D1 و اتصال خودکار شناسه UUID آن به ورکر.
- 📊 **آمار همگانی و آنلاین:** پیگیری و نمایش تعداد کل کاربران و تعداد افراد فعال در ۱۵ دقیقه اخیر با بهره‌گیری از **Upstash Redis**.
- 🧠 **حافظه موقت و دائمی:** ذخیره کلید کاربر در دیتابیس ابری تا نیازی به ورود مکرر کلید در هر بار استارت ربات نباشد.
- 🔙 **سیستم ناوبری یکپارچه:** دکمه‌های بازگشت به منو و لغو عملیات در تمام مراحل برای جلوگیری از سردرگمی کاربر.

## 📋 پیش‌نیازها

پیش از راه‌اندازی، مطمئن شوید اطلاعات زیر را در اختیار دارید:

1. **توکن ربات تلگرام:** از طریق ربات رسمی [@BotFather](https://t.me/BotFather) دستور `/newbot` را ارسال کنید و توکن بگیرید.
2. **اکانت کلودفلر:** یک حساب رایگان در [Cloudflare](https://dash.cloudflare.com/) جهت دریافت API Token.
3. **دیتابیس رایگان Upstash Redis:** وارد [console.upstash.com](https://console.upstash.com/) شوید و یک دیتابیس رایگان بسازید، سپس در بخش REST API مقادیر URL و TOKEN را بردارید.

## ⚙️ متغیرهای محیطی (Environment Variables)

| نام متغیر | وضعیت | توضیحات |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | اجباری | توکن دریافتی از BotFather تلگرام |
| `UPSTASH_REST_URL` | اختیاری / پیشنهادی | آدرس REST دیتابیس آپ‌استش (برای نمونه، آدرسی با دامنه `upstash.io`) |
| `UPSTASH_REST_TOKEN` | اختیاری / پیشنهادی | توکن اتصال به دیتابیس آپ‌استش |

> 💡 اگر متغیرهای Upstash را تنظیم نکنید، ربات اجرا می‌شود اما ذخیره نشست کاربران و آمار همگانی غیرفعال خواهد بود. پیشنهاد می‌شود حتماً تنظیمشان کنید.

## 🚀 راهنمای نصب و راه‌اندازی (صفر تا صد)

### روش اول: اجرا روی سرویس‌های ابری (Botkeep / Zerops / Render / Railway)

1. مخزن پروژه را در سرویس میزبانی موردنظر دریافت یا بارگذاری کنید.
2. متغیرهای محیطی موردنیاز را در تنظیمات سرویس وارد کنید.
3. وابستگی‌ها را از روی `requirements.txt` نصب کنید.
4. دستور اجرای متناسب با سرویس را تنظیم و برنامه را اجرا کنید.

> دستور دقیق اجرا به ساختار پروژه و سرویس میزبانی انتخابی بستگی دارد؛ در متن اولیه دستور مشخصی ارائه نشده است.

### روش دوم: اجرا روی سرور لینوکس (Ubuntu / Debian VPS)

1. Python 3.11 یا 3.12 را نصب کنید.
2. فایل‌های پروژه را به سرور منتقل کنید.
3. وابستگی‌ها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
4. متغیرهای محیطی را تنظیم کنید؛ حداقل `TELEGRAM_BOT_TOKEN` باید مقدار داشته باشد.
5. ربات را با دستور اجرای متناسب با پروژه اجرا کنید.

> دستور اجرای دقیق فایل `bot.py` در متن اولیه مشخص نشده است.

## 📖 نحوه کارکرد ربات برای کاربران

1. **شروع:** کاربر با زدن دکمه شیشه‌ای توکن کلودفلر خود را می‌سازد (تمام تنظیمات دامنه و اکانت روی `All` پیش‌تنظیم است).
2. **انتخاب یا ساخت ورکر:** فهرست ورکرهای موجود به همراه دکمه «➕ ساخت ورکر جدید» ارائه می‌شود.
3. **عملیات دلخواه:**
   - ارسال فایل `worker.js` برای استقرار سریع و دریافت آدرس فعال `workers.dev`.
   - افزودن سکرت‌های رمزشده با تعیین نام و مقدار.
   - ساخت پایگاه داده KV یا D1 با کلیک مستقیم.
